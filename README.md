# STM32-Based Flight Controller PCB

## Project Overview
Designed a 4-layer flight controller PCB around the STM32F405 microcontroller using KiCad. The project integrates motion sensing, environmental sensing, onboard memory, and communication interfaces for an embedded flight control system.

## Key Features
- STM32F405 ARM Cortex-M4 microcontroller
- ICM-42688-P 6-axis inertial measurement unit
- BMP390 barometric pressure sensor
- SPI flash memory
- USB-C and SWD interfaces
- Four ESC PWM output connections
- Power regulation, reverse-polarity protection, and filtering

## Tools & Technologies
KiCad, STM32, I²C, SPI, USB-C, PCB Design, Embedded Systems

## Design Process
1. Designed the circuit schematic and integrated components.
2. Implemented communication and power interfaces.
3. Performed electrical rule checking (ERC).
4. Assigned footprints and developed a 4-layer PCB layout.

## Project Status
Personal PCB design project. Hardware manufacturing and physical testing have not been completed.
